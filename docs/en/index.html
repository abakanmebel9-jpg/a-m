🛠 Фальшпанель vs общий фартук: разбираем детали 🅰 Вариант 1: фальшпанель • Размеры: 900×600 мм, толщина 18 мм (для мат. массив, ЛДСП, МДФ). • Укладка: «шаг» 110 мм, пристегивается к каркасу за винтом, 3‑шаговый монтаж. • Предназначен для глубоких ниш, где «фартук» нельзя растянуть из‑за высоты. • Ошибка: отсутствие вентиляции → гниль в г. массиве.
